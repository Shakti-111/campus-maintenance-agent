## Proposed MVP

A web application for one hostel or academic building that allows users to:

- Submit a maintenance complaint
- Track complaint status
- Review complaint details
- Assign a technician
- Update work status
- Follow up on overdue complaints
- Confirm resolution

## Initial success metrics

- Complaint registration time
- Percentage of complaints requiring clarification
- Routing accuracy
- Duplicate complaint detection accuracy
- Number of manual follow-ups
- Time until confirmed resolution
- Incorrect closure rate

## Problems that AI must not handle autonomously

- Emergency decisions
- Electrical or fire-safety decisions
- Medical or physical-safety decisions
- Payments and purchases
- Technician performance evaluation
- Final complaint closure without authorized confirmation
